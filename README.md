## Descripción
Este repositorio contiene el proyecto desarrollado en Selenium IDE para automatizar pruebas funcionales sobre el sitio web SauceDemo.

## Sitio de prueba
https://www.saucedemo.com/

## Proyecto
Proyecto_VV_Guaña_Roberto

## Suite de pruebas
Suite_Regresion_Basica

## Casos de prueba
- CP01_Flujo_Autenticacion: valida el inicio de sesión exitoso.
- CP02_Login_Fallido: valida el mensaje de error con credenciales incorrectas.
- CP03_Elementos_Dinamicos_Carrito: valida la interacción con el carrito de compras.
